# Portfolio Site Test Plan

## Scope and status

This manual test plan is for the published GitHub Pages site at <https://rs2767-code.github.io/portfolio/>. It covers every header navigation destination and brand link from every page, each page at phone and laptop sizes, every JavaScript feature on every page, keyboard navigation on every page, and Lighthouse Accessibility on every page.

**Live execution status (November 5, 2026): Not run.** The published pages could not be reached with the available browser and web tools. The HTML, CSS, and JavaScript pages currently exist as untracked local files and are not part of the pushed GitHub commit, so the published version may not contain them. No live-site results are claimed. Once the intended version is published and reachable, run each case below. In Actual result, record `Pass` or `Fail`; if a case fails and is fixed, record both the initial failure and retest (for example, `Fail — ...; Retest: Pass — ...`). Include the Lighthouse score.
