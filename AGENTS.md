# Portfolio site requirements

This workspace is for Rakshita's portfolio website. Keep the portfolio organized into these tabs and preserve the supplied facts when building or editing the site:

## HTML structure

- Use semantic HTML5 elements such as `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`.
- Organize content logically within the HTML structure.
- Use exactly one `<h1>` per page.

## Styling and responsive design

- Create and use an external CSS stylesheet to style the website.
- Implement responsive design for phone and laptop screen sizes, using media queries to adjust layouts.
- Keep color schemes and typography consistent across all pages.

## Interactive elements

- Include at least two interactive elements on the website.
- One must be a responsive navigation menu, such as a hamburger menu on mobile devices.
- Other interactive elements may include a project image slider or carousel, contact form validation, a light/dark mode toggle, or animations and effects.

## Accessibility and performance

- Provide appropriate `alt` attributes for images.
- Use sufficient color contrast and ensure the site can be navigated with a keyboard.
- Run Lighthouse in Chrome DevTools and aim for an Accessibility score of 90 or higher.
- Keep each image file under 500 KB.
